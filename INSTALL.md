# Installing iPSX3 Test Cart

## On an iPhone or iPad

1. **Install the PS3 system software.** Open **iPSX3** ▸ **Firmware** tab ▸
   **"Download from Sony…"** ▸ confirm ▸ wait for it to install. iPSX3 cannot start any title until
   this is done. (Or tap "Choose Firmware File…" and pick a `PS3UPDAT.PUP` you already have.)
2. **Download the ROM.** In Safari, open the release page and tap `iPSX3_Test_Cart.iso`. Safari
   saves it to **Files ▸ Downloads**.
3. **Move it into iPSX3.** Open the **Files** app. Touch and hold the file ▸ **Move** ▸
   **On My iPhone / On My iPad ▸ iPSX3**. (Dropping it in **iPSX3 ▸ Games** works too — both
   locations are scanned.)
4. **Play it.** Open **iPSX3**, go to the **Games** tab, and tap **iPSX3 Test Cart**.

## What you should see

- A title bar reading **IPSX3 TEST CART**, and a row of labelled boxes for every controller button.
- **Press any on-screen button — its box lights up immediately.** That is the input test.
- **SCORE / LIVES / FRAME.** The FRAME counter keeps climbing, which shows emulation is running.
- A blue paddle you move with the **D-pad** or the **left stick**; **✕** makes it dash.
  Catch the green blocks, avoid the red ones. After GAME OVER it restarts on **START**, and by
  itself after a few seconds.

## On a Mac (iPSX3 macOS build)

Copy the `.iso` anywhere and open it from the app, or pass its path on the command line.

## Troubleshooting

- **It is not in the Games list.** The file has to be inside the app's own **Games** folder (or the
  top level of the app's folder), not in Downloads or iCloud Drive. Pull down on the Games tab to
  rescan.
- **The Files app does not show iPSX3.** Launch iPSX3 once first — it creates its folders on first
  run.
